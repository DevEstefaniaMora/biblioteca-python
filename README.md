# 📚 Biblioteca Python

Aplicación de consola desarrollada en **Python** para gestionar una biblioteca de libros utilizando **Programación Orientada a Objetos (POO)**.

El sistema permite registrar, consultar, modificar y eliminar libros, además de guardar la información en un archivo JSON para conservar los datos aunque el programa se cierre.

---

## 🚀 Características

✅ Registrar libros nuevos
✅ Mostrar todos los libros registrados
✅ Buscar libros por título
✅ Editar información de un libro
✅ Eliminar libros
✅ Guardar datos en un archivo JSON
✅ Cargar información automáticamente al iniciar el programa

---

## 🛠️ Tecnologías utilizadas

* 🐍 Python
* Programación Orientada a Objetos (POO)
* Manejo de archivos JSON
* Listas y estructuras de datos

## 🧩 Descripción de las clases

### 📖 Clase Libro

Representa un libro dentro de la biblioteca.

Contiene información como:

* Título
* Autor
* Año de publicación

---

### 📚 Clase Biblioteca

Gestiona las operaciones de los libros:

* Agregar libros
* Buscar libros
* Editar libros
* Eliminar libros
* Guardar y cargar información

---

## ▶️ Cómo ejecutar el proyecto

1. Clonar el repositorio:

```bash
git clone URL_DEL_REPOSITORIO
```

2. Entrar a la carpeta:

```bash
cd Biblioteca_Python
```

3. Ejecutar el programa:

```bash
python main.py
```
